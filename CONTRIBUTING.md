# Contribution Guidelines

Thank you for your interest in improving **Easy Fix DeadCode Auditor (EFDC)**!  
Contributions of all kinds are welcome: bug reports, suggestions, code improvements, documentation, and tests.

## How to report an issue (bug or feature request)

1. Go to the **Issues** section of the repository:  
   [https://github.com/robertoabbruzzese/easyfix-deadcode/issues](https://github.com/robertoabbruzzese/easyfix-deadcode/issues)

2. Click on **"New issue"**.

3. Choose a clear title and describe the problem in as much detail as possible:
   - What were you doing?
   - What behaviour did you expect?
   - What behaviour did you get?
   - Attach any logs or output if relevant.

## How to propose code changes

1. **Fork** the repository (the "Fork" button at the top right).

2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/your-username/easyfix-deadcode.git
   cd easyfix-deadcode
   ```
3. Create a branch for your change:
   ```bash
   git checkout -b name-of-your-feature
   ```
4. Make your changes and test them (make sure automated tests pass – if any).

5. Commit and push:
   ```bash
   git add .
   git commit -m "Brief description of the change"
   git push origin name-of-your-feature
   ```
6. Go to your fork on GitHub and click on **"Compare & pull request"**.

7. Submit the pull request, describing what you changed and why.

## Style guidelines
- Follow PEP 8 conventions for Python code.
- Keep comments and documentation in Italian (like the main script).
- Add unit tests when possible.
